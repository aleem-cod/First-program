
# Python Tkinter Calculator

A simple calculator application built with **Python and Tkinter**. This was created as a beginner Python project to practice GUI development, functions, user input, and basic arithmetic operations.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Percentage calculation
* Clear button
* Decimal numbers
* Simple graphical user interface
* Displays the current expression and result

## Technologies Used

* **Python**
* **Tkinter**


## How to Run

### 1. Install Python

Make sure Python is installed on your computer.

### 2. Clone or download this repository

Download the project to your computer.

### 3. Open the project folder

Open the folder in VS Code.

### 4. Run the calculator

Open the terminal and run:

```bash
python calculator.py
```

The calculator window will open.
